# 手工织锦纹样排版台

直接打开 `index.html` 使用（无需构建、无需服务）。

## 功能

- **多套方案**：方案库支持新建、切换、改名、删除；每套方案各自保存网格、用到的色线与各色用量，切换时画布、统计、预览一并跟随。
- **库房库存**：每个色板可直接改库存；用量超过库存时，色板标出“缺线”，网格里对应格位加红虚线框，缺线格单独计数。
- **阻断原因**：导出 JSON 中带 `blocked`、`blockReasons`（逐色说明需多少、存多少、缺多少）和 `missing` 统计，便于上织机前检查。
- 网格绘制、色线统计、撤销重做、断线风险、重复单元预览、本地保存照旧；导出的 `.json` 是纯文本，可直接打开查看。
- 首次打开会自动把旧版单方案存档（`zfl31Pattern`）迁移为“方案一（旧版迁移）”。

## 源码结构（三份独立业务源码）

- `js/canvas-data.js`：画布数据层——网格、填色命中、用量统计、缺线盘点、断线风险、导出数据组装，纯函数无 DOM。
- `js/scheme-store.js`：方案读写层——多方案与库存的 localStorage 增删改查及旧档迁移，不碰页面。
- `js/app.js`：页面操作层——DOM 渲染与全部交互，通过 `BrocadeCanvas` / `BrocadeStore` 调用上面两层。

后续接不同织机时，只需在数据层之外增加适配层，画布计算与方案存档格式可直接复用。
